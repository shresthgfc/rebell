# Naming Rules

All files and folders in this repository must follow these conventions.

---

## Agent file naming

- Use **kebab-case** for all agent filenames
- All names must be **lowercase**
- Agent files must end in `.md`
- Names must describe the role: `security-architect.md`, not `agent-5.md`

---

## Output file naming

- Use **kebab-case** for all output filenames
- All outputs end in `.md`
- Names must match the agent's designated output file
- Phase syntheses follow: `phase-{N}-synthesis.md`
- Debate outputs follow: `debate-{topic-slug}.md`

---

## Forbidden names

Do not use:
- `new-agent`, `test-agent`, `draft`, `tmp`, `wip`, `untitled`, `final`, `v2`

---

## Examples

| Bad | Good |
|-----|------|
| `Agent5.md` | `security-architect.md` |
| `output.md` | `architecture.md` |
| `test.md` | `qa-strategy.md` |
